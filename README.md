## ✨ Features

- Modern dark-themed interface with lime-green accents.
- Responsive layout for desktop, tablet, and mobile devices.
- Hero section featuring automotive imagery.
- Featured vehicle cards with performance specifications.
- Dedicated contact page with a contact form layout.
- Mobile navigation menu with JavaScript interaction.
- Smooth scrolling and hover transitions.
- Reusable CSS styling with custom properties.
- Font Awesome icons and Google Fonts integration.

## 🛠️ Built With

- **HTML5** — Website structure and semantic markup.
- **CSS3** — Responsive layouts, Flexbox, CSS Grid, transitions, and media queries.
- **JavaScript** — Mobile navigation menu interaction.
- **Font Awesome** — Interface icons.
- **Google Fonts** — Montserrat typography.
- **Vercel** — Website deployment.
- **Git & GitHub** — Version control and source code hosting.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/AhmedZakariaAbdo/cars-project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd cars-project
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🎯 Project Goal

This project was built to practice front-end development fundamentals, improve responsive web design skills, and create a polished automotive website using HTML, CSS, and JavaScript.
